# orga+ Landing Page

Landing page for **orga+**, the Windows desktop software to organize, preview and open 3D models offline.

- React 19 + TypeScript + Vite
- Framer Motion animations
- Tailwind CSS with shadcn-style components and the orga+ brand palette
- English / French / Arabic (RTL) and dark / light mode
- Fully responsive (mobile, tablet, desktop)
- Windows desktop application
- All orders go to WhatsApp **+213 770 555 970** (`https://wa.me/213770555970`)

## Run

```bash
cd sites/orgaplus
npm install
npm run dev      # development
npm run build    # production build
npm run preview  # preview the build
```
